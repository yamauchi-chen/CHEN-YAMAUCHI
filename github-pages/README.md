# 大三下的好时候

一款反赌博题材的炒股人生模拟网页游戏 Demo。大三下学期，考研、实习，还有室友推荐的炒股软件：二十个交易日里，玩家用同一份注意力在三条路之间做选择。

**在线试玩**：见右侧 About 栏里的网站链接（建议用电脑浏览器打开，窗口宽度 1280 以上）。

## 这个项目做了什么

- 用 AI 搭建「灵感结构化 → 化学反应检测 → 市场适配打分 → 加权保留」的灵感评估流程，44 条灵感保留核心 26 条。
- 把核心灵感做成可玩 Demo：行情有题材轮动、集合竞价、涨跌停、T+1、融资与配资；生活侧有多轮对话、晚间安排、消费和借贷；共 6 种结局，带跨周目记忆。
- 分工：Claude 写程序、文案和美术提示词，图像模型出图，我负责方向、取舍、试玩和验收。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 作品集页面（项目描述、流程、截图、试玩入口） |
| `play.html` | 游戏本体，原生 JavaScript 单文件，无框架 |
| `demo_art.js` / `demo_art_look.js` | 美术图片包（基础立绘、场景；剪发换装后的立绘） |
| `shots/` | 作品集页面用的截图 |

游戏里的公司、App、学校和人物都是虚构的。
